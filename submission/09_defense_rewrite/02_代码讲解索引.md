# 02 代码讲解索引

这份文件用于现场老师让“打开代码讲一下”时快速定位。

讲法：

## 二、符号表

文件：`src/symbol_table.h`、`src/symbol_table.cpp`

结构：

- `src/symbol_table.h:12`，`SymbolEntry` 表示一处声明
- `src/symbol_table.h:15` 到 `28`，条目内容包括 `name`、`type`、`scope_level`、`offset`、常量标记、引用参数标记、数组信息、record 信息、参数表、返回类型
- `src/symbol_table.h:42`，`SymbolTable` 用作用域栈管理多个作用域
- `src/symbol_table.h:44`，每层作用域是 `unordered_map<string, shared_ptr<SymbolEntry>>`

操作：

- `src/symbol_table.cpp:11`，`enter_scope()` 进入新作用域并重置 offset
- `src/symbol_table.cpp:16`，`exit_scope()` 退出当前作用域，保留全局作用域
- `src/symbol_table.cpp:27`，`insert()` 只向当前作用域插入，并检查同层重复声明
- `src/symbol_table.cpp:42`，`lookup()` 从当前层向外层查找，支持局部变量屏蔽全局变量
- `src/symbol_table.cpp:64`，`add_function()` 把函数和过程登记到全局作用域
- `src/symbol_table.cpp:91`，`TypeSystem::is_compatible()` 支持相同类型和 integer 到 real 的隐式兼容

定位和重定位口径：

- 定位：通过 `lookup()` 找到名字对应的 `SymbolEntry`，条目里有 `scope_level` 和 `offset`，AST 节点里还有源码 `line`、`column` 供错误定位。
- 重定位：本项目不是生成机器码，所以没有目标文件意义上的符号重定位。当前实现里的“重定位”主要体现在两个层面：进入新作用域时 offset 重新计数；代码生成时把 Pascal 数组下界平移到 C 的 0 下标访问，例如 `arr[3]` 生成 `arr[(3) - (3)]`。
